# ASCENT — Credits

This project was built using the following tools and people:

- **User** — Project owner, requirements, design decisions, image prompts, testing
- **Frontend Agent** — React/TypeScript/UI implementation via VTX coding agent harness
- **Backend Agent** — SQL schema, Edge Functions, database logic
- **OpenCode** — AI coding assistant for code generation, debugging, and architecture decisions

## Tools
- **OpenCode** — AI coding agent harness for code generation, refactoring, and problem solving
- **VTX Coding Agent Harness** — Multi-agent orchestration for parallel development (frontend + backend agents)
- **Gemini Image Generator** — Character art, world backgrounds, item/effect images (incoming/ assets)
- **ImageMagick** — Image processing (bg removal, cropping, resizing)

## Image Processing
All game assets were generated by **Gemini Image Generator** and processed with **ImageMagick**:
- Character images: white background removed, cropped, placed in `public/character/`
- World images: resized to 1920px, backgrounds preserved, placed in `public/world/`
- Items/effects: copied from `incoming/` to `public/`

## Backend
- **Supabase** — SQL schema, RLS policies, XP/level functions, Edge Functions (on `backend/initial-schema`)
- **Local Mode** — localStorage-backed cache for offline use (on `frontend`)
